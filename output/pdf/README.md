# Part A submission document - editable content

The PDF is in output/pdf/Fomi-Part-A-Submission.pdf. The reproducible text and layout source is scripts/create-submission-pdf.py. Its first page contains editable name, live Vercel URL and GitHub URL fields. It is not submission-ready until those fields are filled and the hosted application is checked.

The three pages cover:

1. Submission identity, live/repository links, desktop screenshot and scope.
2. Stack, architecture, functional scope, responsive behavior, accessibility, performance and verification.
3. Problem, intended user, three UX decisions, intentionally omitted features, reference inspiration, next-month priorities and the strongest implemented workflow.

The design rationale describes the actual Part A build. It does not claim the supplied visual composition as an original design or replace the separate optional Part B challenge.
